# 🛠️ Timetable Master App Generator

A zero-infrastructure, offline-first web application that automates the compilation of academic master timetables. 

This tool acts as the centralized compilation engine for educational institutions. It ingests individual teacher schedules (in CSV or HTML format) and dynamically generates a standalone, portable **Master Dashboard** featuring Excel-style multi-variable filtering.

---

## ✨ Key Features

* **Zero IT Infrastructure:** Operates entirely client-side within your web browser. No backend servers, databases, or cloud hosting required.
* **Dual File Support:** Parses both standardized `.csv` files and `.html` files (such as those generated by the companion *Teacher Weekly Timetable Generator*).
* **Dynamic App Generation:** Instead of just outputting data, this tool generates an entirely new, fully functional HTML web app (`master_view.html`) that contains your institution's complete schedule.
* **Data Privacy:** Uses the HTML5 File API to read files locally. Institutional data never leaves your computer.
* **Advanced Master Dashboard:** The resulting output file allows administrators and students to instantly filter schedules by Department, Teacher, Class, Time Slot, and Room.

---

## 🚀 How to Use

1. **Launch the Compiler:** Download or clone this repository and double-click `TimeTableGenerator06092026.html` to open it in any modern web browser (Chrome, Edge, Firefox, Safari).
2. **Upload Data:** Click the **Browse...** button and select the individual faculty `.csv` or `.html` files you wish to compile. You can select multiple files at once.
3. **Generate:** Once the files are successfully parsed (a success message will appear), click the **🚀 Download Master View App** button.
4. **Distribute:** A file named `master_view.html` will automatically download. This file is your complete Master Timetable. You can open it to view the schedule or share it directly with students and faculty via email or messaging apps.
